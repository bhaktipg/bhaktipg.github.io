# bhaktipg.github.io

Personal site for Bhakti Patel: Senior Business Analyst (P&C insurance, Guidewire ACE) building data analysis and software engineering skills.

Built with React + TypeScript + Vite. Deployed to GitHub Pages by `.github/workflows/deploy.yml`.

## Editing content

All copy lives in [`src/data/profile.ts`](src/data/profile.ts): roles, projects, skills, credentials. Components only render it.

The resume download is `public/Bhakti_Patel_Resume.pdf`. Replace that file to update it.

## Practice-log stats

`src/data/stats.json` is generated by `scripts/fetch-stats.mjs`. The script reads the
[leetcodesolution](https://github.com/bhaktipg/leetcodesolution) repo through the GitHub API and
classifies each solution (SQL / Python / Pandas). It also counts the SQL concepts and Python
patterns used, plus commits per month.

The deploy workflow runs it on every push and every Monday, so the numbers stay current. If the
API call fails, the committed snapshot is kept.

## Local development

```bash
npm install
npm run stats   # optional: refresh stats.json
npm run dev     # http://localhost:5173
npm run build   # type-check + production build into dist/
```

Append `?theme=dark` or `?theme=light` to the URL to force a theme.

## First-time GitHub Pages setup

Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**. Then push to `main`.
